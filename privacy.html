100% Transparent Privacy & Operating Disclosure

Privacy Policy & Technology Disclosure

EasyTool processes files locally in your browser whenever technically possible. We believe in total honesty: clear badges, no hidden file retention, and explicit disclosures for third-party APIs.

1. No Login 2. Zero File Storage 3. Memory Lifecycle 4. Local vs API Matrix 5. Google Gemini AI 6. Background Cutout 7. Security Standards 8. Ownership

1. No Account & No Mandatory Registration

EasyTool does not require login, registration, phone numbers, email addresses, or personal accounts. You can use every normal utility tool immediately upon visiting the website.

We do not track you across other websites, do not employ aggressive profiling cookies, and do not maintain user databases. The web application is engineered to function frictionlessly as a utility service.

2. Zero Permanent File Storage

EasyTool does not operate any document storage database, permanent cloud file bucket, file upload logs, or file history archive.

For client-side tools (PDF manipulation, image conversion, Python 3 WASM scripts, calculations, encoding, media extraction), your files remain strictly inside your device’s browser memory. Zero bytes of your documents or images are transmitted over the internet to our servers.

Zero Retention Guarantee:
When you download your converted PDF, formatted code, or compressed image, the temporary in-memory Object URL is revoked, and the browser frees the RAM immediately. Nothing lingers on any server.

3. In-Browser Sandboxed File Lifecycle

Every local tool strictly follows this local sandbox lifecycle:

1
Select & Validate
File is read into browser RAM via HTML5 FileReader. Client validates MIME type and file size.
2
Process in WASM
WebAssembly, Canvas, or Web Crypto processes pixels/data locally without network requests.
3
Instant Download
Blob URL is synthesized in client memory and downloaded directly to your local file system.
4
Immediate Eviction
Object URL is revoked, references are cleared, and browser garbage collector reclaims memory.

4. Honest Distinction: Local Tools vs External API Tools

In accordance with our operating principles, we never make false claims such as "100% private" or "no data ever leaves your device" for tools that require external cloud APIs. Every tool is badged honestly:

Criteria 🟢 Local Browser Tools 🔵 External API Tools (AI / BG)
Execution Environment 100% inside your device's browser sandbox (WebAssembly, Web Crypto, Canvas). Secure cloud infrastructure (Google Gemini API / Background.bg).
Network Transmission Zero Bytes Leave Device Secure TLS/HTTPS transmission of user prompt or image.
File Storage by EasyTool Zero Permanent Storage (RAM only) Zero Permanent Storage (ephemeral roundtrip)
Account Required No login, no registration No login, no registration
Examples PDF Merger, Image Converter, GST Calculator, Python WASM, SHA-256 Hasher. AI Prompt Assistant, AI Summarizer, Magic Background Cutout.
UI Badge Shown LOCAL AI • GEMINI API or EXTERNAL API

5. Google Gemini API Technology Disclosure

Selected AI features in EasyTool (such as AI Prompt Assistant, Text Summarizer, and Grammar Evaluator) utilize the official Google Gemini API for natural language processing.

When you submit text to a Gemini-powered tool:

  • Your entered prompt is transmitted through an encrypted EasyTool API proxy layer to Google's API endpoint.
  • EasyTool never saves your prompt or the generated output to any database or analytics store.
  • API secret keys are safeguarded entirely on the backend and are never exposed in client JavaScript.
Mandatory Third-Party Notice:
This feature uses the Google Gemini API to process your input. Your input is securely transmitted to Google's service for computing the response in accordance with Google's API Terms and Privacy Policy.

6. Background Removal API Technology Disclosure

Advanced semantic image background removal requires deep computer vision models. Where local client-side models are technically prohibitive due to download size and memory constraints, EasyTool may route the image to an external processing partner (such as Background.bg).

The image is sent via secure HTTPS, processed solely to produce the cutout PNG mask, returned to your browser for immediate download, and deleted from temporary buffers. EasyTool retains zero copies of uploaded images.

7. Security Standards & Controls

We apply production-grade security engineering principles across EasyTool:

  • Strict HTTPS: All traffic is encrypted using modern TLS 1.3/1.2 protocols.
  • Client-Side Sanitization: All SVGs, HTML snippets, and formatted outputs are sanitized against cross-site scripting (XSS).
  • MIME Type Verification: Strict file boundary checks prevent execution of arbitrary payloads.
  • Memory Safety: Continuous object URL revocation and resource cleanup prevent browser memory leaks.
  • Zero Permanent Logging: No recording of passwords generated in the Password Generator, numbers in Financial Calculators, or contents of merged PDFs.
